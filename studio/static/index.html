1 · 入力

GPU がまだ起動していませんが、ファイルはこのMacで預かっています。 生成する を押したときに自動で転送されるので、このまま プロンプトを書いて進めて大丈夫です。

「高精度」は人物をより正確に再現しますが、VRAM を約1.8倍使います（実測 53 GiB）。48GB の GPU では遅くなることがあります。ふだんは「標準」で十分です。

どこから何を取るかを選ぶと、H3 が理解できる形のプロンプトを作ります。

高いほど元画像そっくりになります。下げると動きは自由になりますが、顔や服が変わりやすくなります。
この値を変えても再エンコードは起きません（キャッシュはそのまま使えます）。
